# Evidence folder

Add the real screenshots captured during your local audit.

Required:
- `lighthouse-accessibility.png`
- `keyboard-tab-navigation.png`
- `carousel-keyboard-focus.png`
- `image-alt-inspection.png`
- `heading-structure.png`

## Lighthouse

Chrome:
1. Open the target URL.
2. DevTools → Lighthouse.
3. Select **Accessibility**.
4. Run the audit.
5. Save a screenshot of the result.
6. Do not manually change the score.

This keeps the submission reproducible and avoids claiming a score that was not actually measured.
