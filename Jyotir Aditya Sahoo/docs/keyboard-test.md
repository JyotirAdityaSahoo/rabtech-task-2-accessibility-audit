# Keyboard-only Navigation Test

## Procedure

1. Open https://edistrict.odisha.gov.in/
2. Disconnect the mouse or deliberately do not use it.
3. Press `Tab` repeatedly.
4. Record every interactive element reached.
5. Use `Shift+Tab` to move backwards.
6. Use `Enter` or `Space` on controls.
7. Verify that focus never becomes trapped.
8. Verify that the visible focus indicator remains obvious.
9. Test Previous/Next carousel controls.
10. Test navigation into and out of service sections.

## Acceptance criteria

- Every interactive control is reachable.
- Focus order is logical.
- Focus is visible.
- Keyboard activation works.
- No component traps focus.
- Users can reach main content efficiently.
- Carousel interaction does not require a mouse.
